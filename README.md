# ARMIN mobile testing demo

**Open the demo:** https://lbicklein.github.io/Armin-Mobile-Testing-Demo/

ARMIN (Asset Reliability & Maintenance Intelligence Network) is a read-only view over AMS Device Manager data:
device health by NAMUR NE 107 status, a priority worklist, and an AMS upkeep scorecard. This page is a single
self-contained HTML file built from demo data recorded on a classroom training skid. It works on phones, tablets
and computers, needs no login, and sends nothing anywhere.

- Tap any ⓘ button to see how a number, status or ranking is decided.
- Each screen has a "How to read this screen" section at the top.
- Windows account names in the audit trail are replaced with "AMS user 1", "AMS user 2" and so on.

This repository only hosts the demo page. The ARMIN source code is kept in a separate private repository.
